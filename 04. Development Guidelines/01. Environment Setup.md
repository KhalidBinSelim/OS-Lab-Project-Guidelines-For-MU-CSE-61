# 01 · Environment Setup

OS projects need a **Linux environment**. Choose one option and make sure **every teammate** has the same tools.

## 1. Choose Your Environment

| Option | Best for | Notes |
|--------|----------|-------|
| **Ubuntu (dual boot)** | Best performance | Needs partitioning; back up first |
| **WSL2 on Windows 10/11** | Most students | Easy; full Linux terminal |
| **Virtual machine** (VirtualBox/VMware) | Safe sandbox | Needs 4 GB+ RAM |
| **Lab machines / SSH server** | No install possible | Keep your own copy on GitHub |

### WSL2 Quick Install (Windows)
Open PowerShell as Administrator:
```powershell
wsl --install -d Ubuntu
```
Restart, create a Linux username/password, then continue below.

> ⚠️ Keep your project **inside the Linux filesystem** (`~/projects/...`), not `/mnt/c/...`, for speed and correct file permissions.

## 2. Install the Toolchain
```bash
sudo apt update
sudo apt install -y build-essential gdb valgrind make git \
                    cppcheck clang-format strace ltrace \
                    manpages-dev manpages-posix-dev
```
Check:
```bash
gcc --version
make --version
gdb --version
git --version
```

## 3. Editor
- **VS Code** (+ extensions: *C/C++*, *GitLens*, *WSL* if using WSL2, *Markdown All in One*)
- or `vim`/`nano` if you prefer the terminal.

```bash
git config --global user.name  "Your Name"
git config --global user.email "your.github.email@example.com"
git config --global init.defaultBranch main
```

## 5. Verify With a Hello-OS Program
```c
// hello_os.c
#include <stdio.h>
#include <unistd.h>
#include <sys/wait.h>

int main(void) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("Child:  PID=%d, PPID=%d\n", getpid(), getppid());
    } else {
        wait(NULL);
        printf("Parent: PID=%d, child was %d\n", getpid(), pid);
    }
    return 0;
}
```
```bash
gcc -Wall -Wextra -o hello_os hello_os.c && ./hello_os
```
If this prints both lines, your environment is ready.

## 6. Useful Tools You Will Use Often

| Tool | Purpose | Example |
|------|---------|---------|
| `gcc -Wall -Wextra -g` | Compile with warnings + debug info | |
| `make` | Build automation | `make`, `make clean`, `make test` |
| `gdb` | Step-through debugger | `gdb ./app` → `break main`, `run`, `next`, `print x` |
| `valgrind` | Memory leaks / invalid access | `valgrind --leak-check=full ./app` |
| `-fsanitize=address,undefined` | Fast bug detection | add to CFLAGS in debug builds |
| `strace` | Show system calls | `strace -f ./myshell` |
| `ps`, `top`, `ls /proc` | Inspect processes | `ps aux` |
| `ipcs`, `ipcrm` | Inspect/remove IPC objects | `ipcs -a` |
| `man 2 fork` | Manual page for system call | `man 2 pipe` |

## 7. Troubleshooting

| Problem | Fix |
|---------|-----|
| `gcc: command not found` | `sudo apt install build-essential` |
| `Permission denied` running a file | `chmod +x file` |
| `undefined reference to pthread_create` | Compile with `-pthread` |
| `undefined reference to sem_init` | Compile with `-pthread` |
| `undefined reference to mq_open` | Link with `-lrt` |
| WSL very slow | Move project out of `/mnt/c` |
| Windows line endings (`^M`) | `git config --global core.autocrlf input` |
