# OS Lab Project Guidelines For MU (CSE 61)

> **Course:** Operating System Lab (CSE 322) · **Metropolitan University, Sylhet**
> **Instructor:** Khalid, Lecturer, Dept. of CSE

This repository is your **complete handbook** for the OS Lab Project. There is no final exam for this lab. Instead, you will **build a project, submit it on GitHub, present it, and answer questions about every part of it.**

If you have never built an OS-related project before, that is completely fine. This guide starts from zero.

---

## The One Rule That Matters Most

> **You may use AI to help write code. You may NOT submit code you cannot explain line by line.**

During the presentation and Q/A, you will be asked to explain *any* part of your code, change it live, or predict its output. A working project you cannot explain scores low. A smaller project you fully understand scores high.
