# Idea 03 · Memory Management Simulator (Paging + Page Replacement)

## 1. Overview
Simulates how an OS maps **virtual pages to physical frames**, handles **page faults**, and applies replacement algorithms, optionally with a **TLB** and a **contiguous allocation** module.

**Difficulty:** ⭐⭐ · **Language:** C or Python

## 2. OS Concepts Covered
Virtual memory · page table · frames · page faults · TLB · FIFO / LRU / Optimal / Clock · Belady's anomaly · fragmentation · first/best/worst fit

## 3. Features

### Must
- Input: page reference string + number of frames (file or manual)
- FIFO, LRU, Optimal replacement
- Step table showing frame contents after each reference (`H`it/`F`ault)
- Total faults, hit ratio, fault ratio

### Should
- Clock (second-chance) algorithm
- Comparison across frame sizes (1..N) with a text chart
- **Belady's anomaly demonstration** for FIFO (`1 2 3 4 1 2 5 1 2 3 4 5`)
- Random reference string generator with locality

### Could
- Address translation: logical address → page number + offset → physical address
- TLB simulation with hit/miss rate and effective access time
- Contiguous allocation: first/best/worst fit with fragmentation report
- Multi-process memory with per-process page tables

## 4. Suggested Design
```
src/
├── main.c / menu.c
├── refstring.c        # input + generator
├── fifo.c  lru.c  optimal.c  clock.c
├── translate.c        # address translation (optional)
├── tlb.c              # (optional)
└── report.c           # tables and charts
```
Common interface: `Result simulate_xxx(int *refs, int n, int frames);`

## 6. Demo Scenario
1. Run the Belady reference string with 3 and 4 frames under FIFO → faults **increase**.
2. Run LRU on same input → no anomaly. Explain why (stack algorithm).
3. Show comparison table of all four algorithms.
4. (Twist) Translate address `0x1A3F` with page size 1 KB.

## 7. You Must Be Able To Explain
- Why Optimal is impossible in real systems but useful as a benchmark
- How LRU is implemented in your code (timestamps? stack?) and its cost
- What a page fault physically triggers in a real OS
- Page number/offset math: `page = addr / page_size`, `offset = addr % page_size`
- Why Belady's anomaly occurs for FIFO but not LRU

## 8. Pitfalls
- Off-by-one errors in frame arrays
- Optimal: forgetting the "never used again" case
- Using LRU timestamps incorrectly on hits (must update on hit too)
- Not resetting state between algorithm runs

## 9. Exceptions
Visual frame animation in terminal · working-set model · workload generator for "sequential vs random vs looping" patterns · analysis on which algorithm wins per pattern
