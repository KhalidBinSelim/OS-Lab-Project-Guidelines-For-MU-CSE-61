# 03 · Timeline

A realistic plan for roughly **1 month**. Adjust to the real deadline announced later.

## Overview

| Phase | When | Goal | Output |
|-------|------|------|--------|
| **Week 0** | Days 1–3 | Team + idea + proposal | Approved proposal, repo created |
| **Week 1** | Days 4–10 | Foundations + skeleton | Project builds, first feature runs |
| **Week 2** | Days 11–17 | Core features (MVP) | **MVP demo works end-to-end** |
| **Week 3** | Days 18–24 | Extra features + testing | Feature complete, tests pass |
| **Week 4** | Days 25–30 | Freeze, docs, rehearsal | Final submission + practice |

## Red Flags

| Warning sign | What to do |
|--------------|------------|
| End of Week 1 and nothing runs | Cut scope immediately |
| Nobody can explain a module | Schedule a teach-back now |
| Big untested code dump | Break it down, test piece by piece |
| Only one person commits | Redistribute tasks today |
