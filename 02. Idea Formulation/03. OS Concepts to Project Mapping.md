# 03 · OS Concepts → Project Mapping

Use this table to link **theory topics** to **buildable features** and to **system calls / APIs** you may use.

## Mapping Table

| OS concept | What you can build | Key system calls / APIs / structures |
|------------|--------------------|---------------------------------------|
| Process creation | Shell, job runner | `fork`, `exec*`, `wait`, `waitpid`, `exit` |
| Process states & PCB | Scheduler / monitor | `struct PCB`, `/proc/<pid>/stat` |
| CPU scheduling | Scheduler simulator | Queues, priority queue, time quantum | 
| Threads | Sync lab, parallel tasks | `pthread_create`, `pthread_join` |
| Race conditions | Bank/counter demos | Shared variable, `pthread_mutex_t` |
| Semaphores | Producer–consumer | `sem_init`, `sem_wait`, `sem_post` | 
| Deadlock | Banker's, RAG detection | Matrices, graph cycle detection | 
| Contiguous allocation | Memory allocator sim | First/Best/Worst fit, free list | 
| Paging | Page-table simulator | Frames, page table, TLB | 
| Page replacement | Replacement simulator | FIFO, LRU, Optimal, Clock | 
| File system | Mini FS | Inodes, directory table, bitmap | 
| Disk scheduling | Disk head simulator | FCFS, SSTF, SCAN, C-SCAN, LOOK | 
| Pipes | Shell pipelines, IPC | `pipe`, `dup2`, `read`, `write` | 
| Message queues | Job server | `msgget`, `msgsnd`, `msgrcv` | 
| Shared memory | Fast IPC | `shmget`, `shmat` or `mmap` | 
| Signals | Shell, monitor | `signal`/`sigaction`, `kill` | 
| Virtual file system | System inspector | `/proc`, `opendir`, `readdir`, `stat` | 

## How To Use This
1. Circle the concept(s) you **already studied in the OS lab**. They are the safest base.
2. Pick **one** row as the primary concept.
3. Check the "What you can build" column for inspiration.
4. Make sure you can explain every API in the third column.

## Concept Depth Checklist
For your primary concept, you should be able to answer:
- What **problem** does this OS mechanism solve?
- What is the **algorithm / data structure**?
- What are its **advantages and disadvantages**?
- What are **real operating-system examples** (Linux, Windows)?
- How does **your project** model or use it?
